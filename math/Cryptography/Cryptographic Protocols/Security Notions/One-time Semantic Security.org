One-time semantic security says that one ciphertext under a fresh secret key
does not efficiently reveal which of two chosen messages was encrypted. Here
the term uses the course's indistinguishability formulation.

* Experiment

Let \(\Pi=(E,D)\) be a secret-key cipher. For a fixed \(b\in\{0,1\}\),
experiment \(\mathsf{SS}_b(A,\Pi)\) proceeds as follows:

1. \(A(1^\lambda)\) chooses admissible equal-length messages \(m_0,m_1\)
   and retains its internal state.
2. The challenger samples a uniform key \(k\in\mathcal K\), computes
   \(c\leftarrow E(k,m_b)\), and sends \(c\) to \(A\).
3. \(A\) outputs a bit; the experiment returns that bit.

All encryption coins are fresh. Define

\[
p_b=\Pr[\mathsf{SS}_b(A,\Pi)=1],
\qquad \operatorname{SSAdv}[A,\Pi]=|p_0-p_1|.
\]

The cipher is secure if this advantage is negligible for every PPT \(A\)
[cite:@fioreCryptographicProtocolosApplicatons sec. 2.2].

* Equivalent guessing game

Instead sample \(b\) uniformly and let \(\widehat b\) be the adversary's
guess. With the same strategy and output labels, define

\[
\operatorname{SSAdv}^{*}[A,\Pi]
=\left|\Pr[\widehat b=b]-\tfrac12\right|.
\]

Since \(\Pr[\widehat b=b]=\tfrac12(1-p_0+p_1)\),

\[
\operatorname{SSAdv}[A,\Pi]
=2\operatorname{SSAdv}^{*}[A,\Pi].
\]

The absolute value also counts a strategy that consistently reverses the
correct answer. The factor of two matters in concrete reduction bounds.

* Examples and limits

The one-time pad has zero advantage even against unbounded adversaries.
Masking with a secure PRG instead gives computational one-time security.

Equal-length challenges allow ciphertext length to reveal message length.
Padding is a separate mechanism if length itself must be hidden.

There are no encryption or decryption oracles in this game. Security here does
not justify reusing a PRG pad or encrypting many messages under the same key.
